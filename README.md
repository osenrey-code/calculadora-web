# Calculadora web

Calculadora desarrollada con **HTML5, CSS3 y JavaScript (ES5)**. Permite realizar las operaciones básicas de suma, resta, multiplicación y división, y conserva el historial en `localStorage` hasta que el usuario decide eliminarlo.

## Funcionalidades

- Suma, resta, multiplicación y división.
- Validación de división entre cero.
- Historial persistente mediante `localStorage`.
- Botón para borrar el historial con confirmación.
- Uso mediante botones o teclado físico.
- Diseño adaptable para computadoras y teléfonos.
- Interfaz accesible con etiquetas y estados de enfoque.

## Cómo ejecutar

No requiere instalaciones. Abre `index.html` en cualquier navegador moderno.

## Controles del teclado

- Números: `0`–`9`
- Operadores: `+`, `-`, `*`, `/`
- Calcular: `Enter` o `=`
- Borrar último dígito: `Backspace`
- Limpiar calculadora: `Escape` o `Delete`
